# Smart-Driver-Tracker
A mobile driving safety app built with Expo and React Native. Tracks driving behavior in real time and surfaces safety insights for both teen drivers and their parents.

## Features
- **Live Trip Tracking** — monitors elapsed time, current speed, and distance traveled in real time
- **Teen Dashboard** — personal driving history with trip logs and a safety score
- **Parent Dashboard** — family member selector, safety score overview, recent trips, and alerts for dangerous driving events (harsh braking, speeding)
- **Trip History** — full log of past trips with date, distance, and duration
- **Safety Alerts** — flags events like harsh braking and speed exceeded 120 km/h

## Tech Stack
- [Expo](https://expo.dev/) — cross-platform mobile framework
- React Native — UI components and navigation
- JavaScript — application logic

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) installed
- [Expo Go](https://expo.dev/client) app on your phone (for mobile testing)

### Installation

```bash
# Clone the repo
git clone https://github.com/DisguisedMax/Smart-Driver-Tracker
cd Smart-Driver-Tracker

# Install dependencies
npm install

# Start the dev server
npx expo start
```

Then scan the QR code with Expo Go on your phone, or press `w` to open in browser.
